    Tentang Aplikasi

    Ngeteng ke Semarang adalah aplikasi storytelling interaktif UAS yang merupakan pengembangan dari proyek UTS Sistem Multimedia.

    Ceritakan pengalaman backpacker dari Bandung ke Semarang dengan budget terbatas. Setiap keputusan mempengaruhi budget, poin, dan akhir ceritamu.

    • Mata Kuliah Sistem Multimedia
    • Versi 2.0 — UAS Edition
    • Teknologi HTML + CSS + JavaScript
    • Multimedia Teks, SVG, Canvas Video, Web Audio
    • Total Scene 6 scene + 3 ending
    • Fitur Baru Poin, Simpan Data, Riwayat, Video
